# 🎉 真心话大冒险

一个基于微信小程序开发的社交互动小程序，支持多人联机游戏。

## ✨ 功能特性

- 🏠 **房间管理**：创建房间、加入房间、房间列表展示
- 👥 **玩家管理**：查看玩家列表、房主权限、踢人功能
- 💬 **真心话**：随机问题库、挑战进行状态
- 🚀 **大冒险**：随机任务库、搞笑挑战
- 💌 **留言板**：实时留言、点赞、笑死表情互动
- 📊 **排行榜**：游戏统计、积分排名、挑战记录

## 📁 项目结构

```
.
├── miniprogram/          # 微信小程序原生代码
│   ├── pages/            # 页面
│   │   ├── home/        # 首页
│   │   ├── room/        # 房间页
│   │   ├── game/        # 游戏页
│   │   ├── message/     # 留言板
│   │   └── result/      # 结果统计
│   ├── images/          # 图片资源
│   ├── app.js           # 小程序入口
│   └── app.json         # 小程序配置
├── src/                 # Taro 框架源码（React + TypeScript）
└── cloudfunctions/      # 云函数
```

## 🎮 使用说明

### 微信小程序

1. 在微信开发者工具中打开项目
2. 修改 `project.config.json` 中的 `appid` 为你的小程序 AppID
3. 点击「编译」按钮即可预览

### Taro 项目

1. 安装依赖：`npm install`
2. 开发模式：`npm run dev:weapp`
3. 生产构建：`npm run build:weapp`
